A folder of useful tools for your USB stick. Run one file, pick the tools you want, and they install onto the stick.

Set it up in three steps

  1. Put it on the stick

    Download the zip and unzip it onto your USB drive.

  2. Run one file

    Open a terminal in the folder and run the launcher shown in the download menu above (run.bat on Windows, ./run.sh on macOS and Linux).

    You need Python 3.8 or newer. Any system with Python can also use python run.py.

  3. Pick your tools

    A page opens in your browser. Select a tool or two and choose Install selected, or install everything for that computer.

    Good to know

    Most tools open the official download page.
    Vendors change their download links often, so Glovebox sends you to the source instead of a copy that could go stale. Sysinternals downloads directly.
    Everything stays on the stick.
    Glovebox writes only inside its own folder. Its local page listens on your computer only, never the network.
    Add your own tools.
    Edit tools/catalog.json in the folder. The README shows the format.

    Glovebox is free to use. Third-party tools belong to their authors and keep their own licences.
